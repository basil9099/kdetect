=== why zeros for non-root when kptr_restrict=0? ===
perf_event_paranoid = 3
kptr_restrict       = 0

kallsyms_show_value() falls through case 0 to case 1 unless
kallsyms_for_perf() is true, which requires perf_event_paranoid <= 1.
So with perf_event_paranoid > 1, CAP_SYSLOG is required regardless
of kptr_restrict being 0. TWO sysctls gate kernel address visibility.

CONSEQUENCE: kdetect needs root (or CAP_SYSLOG) for ANY address-based
detection - module base addresses, syscall table, symbol hooking.
