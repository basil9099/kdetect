----------------------------------------------------------------------

Module code lives in a vmalloc region allocated at load time. The
allocation is released on unload, not on unlinking, so a hidden
module should still own a region here. Unlike ftrace this needs no
tracing subsystem, but it gives an address range rather than a name.
