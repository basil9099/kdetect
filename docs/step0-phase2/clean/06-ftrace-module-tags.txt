ftrace records a module's traceable functions when the module is
LOADED, and drops them when it is UNLOADED. Unlinking a module from
the kernel's `modules` list is neither, so if these records survive
hiding, this is a channel that does not share a source with
/proc/modules. That is the whole question this file answers.
