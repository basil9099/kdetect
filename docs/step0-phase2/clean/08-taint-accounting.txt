Loading an out-of-tree unsigned module sets taint bits 12 and 13.
Unlinking the module from the list does not clear them. So a kernel
that admits to an out-of-tree module while no listed module carries
an (O) or (E) marker is accounting for something it will not name.
This costs two file reads and needs no tracing and no addresses.
